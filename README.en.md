**Title**
Ingrid Bianchi's Personal Portfolio

**Description**
This is my personal portfolio, built with Next.js, where I showcase my skills and experience as a full-stack developer. The application has a single-page structure with sections to display information about me, my projects, and skills.

**Features**
* **Server-side Rendering:** The application uses Next.js to render pages on the server, which improves user experience and SEO.
* **Static Site Generation:** The application can generate static pages to improve performance and reduce server load.
* **Dynamic Routing:** The application uses a dynamic routing system to create custom routes for pages.
* **Internationalization Support:** The application has support for internationalization (i18n) and localization (l10n), allowing me to display content in different languages.

**Technologies Used**
* **Next.js:** React framework for building scalable web applications.
* **React:** JavaScript library for building user interfaces.
* **CSS-in-JS:** I use CSS-in-JS to customize the application's styling.
* **JavaScript:** Programming language used to create the application logic.

**Installation and Execution**
To run the application, follow these steps:

1.  Clone the repository:
    ```bash
    git clone https://github.com/IngridBianchi/Portafolio-Next.git
    ```
2.  Install the dependencies:
    ```bash
    npm install
    ```
3.  Run the application:
    ```bash
    npm run dev
    # or
    yarn dev
    # or
    pnpm dev
    # or
    bun dev
    ```
